홈 대시보드 (Dashboard Overview)

/ · 메인 화면
ANALYTICS
접속하면 가장 먼저 보이는 모니터링 허브. 시장 동향과 위험 신호를 한 화면에서 조기 감지합니다.

이 탭으로 무엇을 하나

  • 전달 대비 약가 변동 Top 10 을 즉시 확인
  • 정책·뉴스 키워드 클라우드로 이슈 흐름 파악
  • MSD 자산 등재현황·파이프라인·경쟁 동향 스냅샷

주요 기능

  • 약가변동 테이블 — 제품·성분·제약사·변동전가/현재가·변동률·사유·적용일
  • 행 클릭 시 국내약가 탭으로 바로 이동
  • 키워드 클라우드 — 글자 크기=언급 빈도, 클릭 시 근거 기사 연결
  • MSD 요약 카드 3종 — 등재 / 파이프라인 / 경쟁사

데이터 출처

월별 자동 수집·집계된 데이터입니다.

국내약가 (Domestic Pricing)

/domestic-pricing
ANALYTICS
건강보험(HIRA) 약가를 검색하고, 가격 변동 이력과 그 사유, 동일성분 비교약제까지 한 번에 분석합니다.

이 탭으로 무엇을 하나

  • 제품·성분·보험코드로 약가 상세 조회
  • 약가 변동 이력 + 변동 사유 근거 확인
  • 동일성분 비교약제와 약가·일일투약비 비교

주요 기능

  • 검색 + 엑셀 다운로드 (검색결과 XLSX)
  • 기본/상세 카드 — 최초 등재일·현 상한가·RSA 여부·허가일·용법용량·일·월·연 치료비
  • 비교약제 최대 3종 추가 → 기준약제 대비 차이율
  • 가격 워터폴 차트 + 변동이력 테이블
  • 사유 분석 클릭 → 4대 기전 분류 + 신뢰도 배지 + 근거문헌

데이터 출처

HIRA 급여목록 고시 식약처 허가정보 API PubMed·MA 전문지
출처 표시 — 허가일은 식약처 공식 또는 추정으로 구분. RSA 품목은 표시가 ≠ 실거래가(net 비공개) 임을 유의.
활용 팁 — "사유 분석"은 처음 누르면 20~40초 걸리지만 결과는 영구 저장돼 다음부터 즉시 표시됩니다. 신뢰도 '높음' 근거 위주로 보고에 인용하세요.

해외약가 (International Pricing)

/international-pricing
ANALYTICS
A8 8개국 약가를 조사해 한국 기준 조정가(A8 adjusted price)와 일일투약비를 산출합니다. 재정영향분석의 근거 자료가 됩니다.

이 탭으로 무엇을 하나

  • 미국·영국·독일·프랑스·캐나다·일본·이탈리아·스위스 약가 조회
  • 현지가 → 한국 조정가(KRW) 환산
  • 국가별 급여 여부와 일일투약비 비교

주요 기능

  • 조정가 요약 카드 — 최저/평균/최고가 + 평균 제외국 사유
  • 국가별 비교 그래프 + 8개국 카드(급여 배지·현지가·조정가·일일비)
  • 조정가 산출 로직 펼치기 — 표시가→단위가→환율→공장도율→VAT→조정가 전 과정 공개
  • 검색 이력 카드 / 신규 검색 / 리포트 다운로드

데이터 출처

각국 공개 의약품 DB US: Micromedex(WAC) KEB 36개월 평균환율
환율 — KEB하나은행 36개월 평균(최종 고시회차). 매월 2일 자동 갱신되어 모든 조정가에 일괄 반영됩니다.
활용 팁 — 조정가가 비어 있는 국가는 "미등재/가격 미공개" 사실이며 임의 추정값이 아닙니다. 산출 로직을 펼치면 각 단계 수치를 그대로 재정영향분석서에 옮길 수 있습니다.

관리자 영역 (MANAGEMENT)
아래 7개 탭은 관리자 전용입니다. 분석 탭에 표출되는 데이터를 입력·관리하는 백오피스 기능입니다.

A1 · 시장점유율 업로드  |  A2 · MSD 파이프라인

  • A1 — IQVIA 분기 Excel 업로드 → "국내 시장(4)" 탭 데이터 갱신. 업로드 이력·현황 요약 제공.
  • A2 — MSD 개발 중 제품(개발단계·적응증·예상출시년) CRUD → 홈 MSD 요약 카드에 반영.

A3 · 브랜드 트래픽  |  A4 · MNC 동향 관리

  • A3 — 홈 브랜드 순위(Top10)·7일 스파크라인·뉴스 블럭 관리.
  • A4 — "경쟁사 동향(5)" 카드 CRUD + 주1회 자동 크롤 실행(Naver+GPT 필터).

A5 · 키워드 클라우드  |  A6 · 급여 관리

  • A5 — 홈 키워드 클라우드 단어·가중치·색상 관리.
  • A6 — 제품별 적응증 급여 여부(boolean)·조건·공고 수동 편집 → "급여 현황(7)" 반영.

A7 · 심의 파이프라인 관리

  • 약평위 심의 대기 약제 등록·상태 추적(제출~재심의)
  • 심의 회차(Session) 생성·편집 + 회차별 이벤트 관리
  • NHIS 약가협상 자료와 미매칭 약제 수동 매칭
관리 원칙 — 모든 관리 입력은 즉시 DB 에 반영되어 분석 탭에 표출됩니다. 자동 수집 데이터는 관리자 수동 편집분을 덮어쓰지 않도록 보존됩니다.

데이터 흐름은 단방향

  • 스크레이퍼(자동 수집) → DB → 대시보드
  • 화면은 DB만 읽으므로 매 검색마다 외부를 다시 긁지 않음 → 빠르고 일관됨

  • 급여 net 가격은 비공개 — 표시가는 net 이 아님(RSA)
  • 가격 없음은 "미등재/미공개" 사실, 임의값 아님
