홈 대시보드 (Dashboard Overview)

/ · 접속 시 첫 화면
ANALYTICS
바쁜 아침, 어제까지의 약가 변동과 정책 이슈를 한 화면에서 5분 안에 파악합니다.
이럴 때 사용하세요
월요일 아침, 지난주 약가가 어떻게 바뀌었는지 빠르게 보고해야 할 때
→ 약가변동 Top 10 테이블로 변동 큰 품목·사유·변동률을 즉시 확인
정부·정책 이슈가 요즘 뭐가 뜨고 있는지 감을 잡고 싶을 때
→ 키워드 클라우드로 언급량 많은 이슈 파악, 클릭하면 근거 기사로 연결
팀 회의 직전, 우리 자산·경쟁 상황 한 장 요약이 필요할 때
→ MSD 요약 카드(등재·파이프라인·경쟁) 스냅샷 활용

주요 기능

  • 약가변동 Top10 — 변동전가/현재가·변동률·사유·적용일
  • 행 클릭 → 국내약가 탭으로 바로 이동
  • 키워드 클라우드 — 글자 크기 = 언급 빈도
  • MSD 요약 카드 3종

데이터 출처

HIRA 고시네이버 뉴스MSD 파이프라인
월별 자동 수집·집계분. 별도 조회 없이 항상 최신 적재 데이터.
활용 팁 — 변동률이 큰 품목은 행을 눌러 국내약가에서 변동 사유까지 확인하면, 바로 그 이유를 보고서에 인용할 수 있습니다.

국내약가 (Domestic Pricing)

/domestic-pricing
ANALYTICS
건강보험 약가의 현재가·변동 이력·변동 사유·비교약제를 한 번에 분석합니다.
이럴 때 사용하세요
"이 약 지금 상한가가 얼마고, 등재 후 얼마나 떨어졌지?" 가 궁금할 때
→ 검색 후 기본 카드 + 가격 워터폴 차트로 등재일부터의 변화 한눈에
우리 약 일일투약비가 동일성분 경쟁약 대비 어느 수준인지 봐야 할 때
→ 비교약제 최대 3종 추가 → 약가·일치료비·차이율 자동 비교
"약가가 왜 인하됐는지" 근거를 보고서에 써야 할 때
→ 변동이력 행의 사유 분석 → 4대 기전 분류 + 신뢰도 + 근거문헌

주요 기능

  • 제품·성분·보험코드 검색 + 엑셀 다운로드
  • RSA 여부·허가일·용법용량·일·월·연 치료비
  • 가격 워터폴 + 변동이력 테이블
  • 사유 분석(기전·신뢰도·참고문헌)

데이터 출처

HIRA 고시식약처 허가 APIPubMed·전문지
허가일은 공식/추정 칩으로 구분. RSA 품목은 표시가 ≠ 실거래가(비공개).
활용 팁 — "사유 분석"은 처음만 20~40초 걸리고 결과는 영구 저장돼 다음부터 즉시 표시됩니다. 신뢰도 '높음' 근거를 우선 인용하세요.

해외약가 (International Pricing)

/international-pricing
ANALYTICS
A8 8개국 약가를 한국 기준 조정가(KRW)로 환산해, 약가협상·재정영향분석 근거를 만듭니다.
이럴 때 사용하세요
신약 약가협상 준비로 A8 국가 참조가격이 필요할 때
→ 영문 성분/제품명 검색 → 8개국 조정가 카드 + 비교 그래프
재정영향분석서에 들어갈 조정가 산출 근거가 필요할 때
→ 조정가 산출 로직 펼치기 → 표시가·환율·공장도율·VAT 전 과정 그대로 인용
특정 국가의 급여 여부·일일투약비를 비교해야 할 때
→ 국가별 카드의 급여 배지·일일 치료비로 즉시 대조

주요 기능

  • 최저/평균/최고가 요약 + 평균 제외국 사유
  • 8개국(US·UK·DE·FR·CA·JP·IT·CH) 카드
  • 산출 로직 전체 공개(검증용)
  • 검색 이력 · 리포트 다운로드

데이터 출처

각국 공개 약가 DBUS: WACKEB 36개월 환율
환율은 최종 고시회차 36개월 평균, 매월 자동 갱신. 빈 국가는 "미등재/미공개" 사실이며 추정값 아님.
활용 팁 — 산출 로직을 펼치면 각 단계 수치를 그대로 재정영향분석서에 옮길 수 있어, 별도 계산 없이 근거 표가 완성됩니다.

ANALYTICS
치료군(ATC4) 단위로 점유율과 분기별 매출·처방량 추이를 분석합니다.
이럴 때 사용하세요
우리 제품의 시장 위치(점유율)를 치료군 안에서 파악할 때
→ 제품 검색 → 도넛 차트 + 점유율 순위로 위치 확인
분기 실적 리뷰에서 경쟁 브랜드 매출·유닛 추이가 필요할 때
→ Revenue / Unit Trend 뷰로 분기별 흐름 비교
신제품 런칭 후 시장 침투가 잘 되고 있는지 추적할 때
→ 분기 추이에서 점유율·유닛 상승 곡선 모니터링

주요 기능

  • 제품/성분 검색 → 브랜드 상세 카드
  • 3가지 뷰: Market Share / Unit / Revenue
  • 상위 6 + Others 점유율 요약
  • 엑셀 다운로드 · 다크/라이트 모드

데이터 출처

IQVIA NSA-E관리자 분기 업로드

활용 팁 — Revenue Trend 로 보면 점유율은 낮아도 매출이 크는 품목을 잡아낼 수 있습니다.
