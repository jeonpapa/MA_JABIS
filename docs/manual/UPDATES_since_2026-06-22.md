## 1. 투약비용비교 탭 — 신규 추가 ⭐

레지멘(항암요법) 단위로 **일·월·연 치료비**를 비교하는 새 탭이 생겼습니다.

- **항암 레지멘 정본 DB 기반**: HIRA 항암요법 공고 144개 레지멘을 정본으로 탑재. 레지멘을 고르면 구성 약제·표준 용법용량이 자동으로 채워집니다.
- **환자 파라미터 반영 용량 계산**: 체표면적(BSA)·신기능(Calvert AUC)·체중(mg/kg) 기반으로 환자별 실제 투여량(mg)을 산출 → 약가와 곱해 사이클·코스·월·연 비용 계산. 환자 파라미터 패널은 열람·수정 가능(기본값=계산기 표준값).
- **as-of 시점 약가 + 주성분 가중평균(WAP)**: 특정 시점의 약가, 또는 동일 주성분 가중평균가로 비교. 시점·소스 컨트롤은 표 가까이 배치.
- **레지멘=시작 템플릿, 약제 자유 편집**: 불러온 뒤 약제 삭제·추가·용량 편집 자유. **편집 내용은 영구 저장**되어 다시 열면 그대로 복원. 비항암 약제는 허가사항(MFDS) 기반 용법으로 계산.
- **커스텀 레지멘 영구 라이브러리**: 직접 만든 레지멘을 저장·검색·재사용(팀 공유). 저장 상태는 북마크 아이콘으로 표시.
- **그래프 + 비교 테이블**: 그래프 하단에 레지멘별 비용 비교 표.
- **살아있는 엑셀 다운로드**: 수식이 살아있는 xlsx로 내보내기(값이 아닌 계산식 포함).

## 2. 해외약가 — 제형(formulation)별 비교로 재설계 ⭐

기존 'cross-strength 용량 정규화' 방식을 폐기하고 **제형(강도 × 투여경로) 단위 그룹핑**으로 전환했습니다.

- **제형 탭 UI**: 한 약을 검색하면 제형별로 탭이 나뉘어 국가 간 비교가 공정해짐(미국 표기를 canonical 기준). 예: Prevymis는 제형별 탭으로 분리.
- **제형 내 표시단위 보정**: 같은 제형 안에서 국가별 표기 단위 차이를 보정.
- **미가격(강도만) 행도 표시**: 가격이 없는 행도 같은 제형 탭에 '가격 미공개'로 함께 노출.
- **A8 리포트 다운로드**: 조정가 리포트를 xlsx + hwpx(한글) 형식으로 내보내기.

## 3. 아날로그(약제 등재) 분석 — 대폭 보강 ⭐

- **추가 약제결정신청서 56건 적재**: DREC 추가 자료 반영(분석 대상 680 → 735건).
- **약평위 결과 검증·보완 + 게시물 바로가기**: 약평위 전체목록 메타(871건)로 기존 결과를 교정·보완. 상세모달 헤더에 해당 **약평위 게시물 링크 아이콘** 추가.
- **'급여 등재' 타임라인 단계 추가**: 국내약가 API의 최초 약가 등재일을 타임라인에 추가하고 **'최초 허가 → 급여 등재'** 구간을 강조(587건 반영).
- **RSA·사후조건 Tier1 미디어 보완**: 위험분담제(RSA)·사후조건부 약제 76종에 대해 급여 등재 시점 ±2개월의 전문지(데일리팜·약업신문·메디파나·히트뉴스) 보도를 조사 → 상세모달에 **'RSA·사후조건 미디어 보완'** 블록(조건·모니터링·출처 링크)으로 표시. PDF 원본 RSA 정보와 별도 보존.
  - 룰: 약평위 결과는 신약만 공개되므로 정보는 "최초 약가 등재 시점"에 유효(검색 윈도우를 급여등재일에 앵커), 근거 없으면 표기하지 않음.
